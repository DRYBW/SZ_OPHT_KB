## 0. 一句话规则

**凡问题存在上游成因，一律修上游；下游补丁只作临时措施且必须带到期日与上游修复指向。**

链路（上游 → 下游）：

| 层 | 职责 | 权威件 | 本层该修的问题类型 |
|---|---|---|---|
| L0 数据面 | 卷/真值/泄漏审计 | 建卷件 + LEAK_AUDIT | 卷构成、真值口径、池对撞 |
| L1 知识面 | KB 词表/本体/组成先验 | KB 版本件（v4.1/v5x）+ 类型清点表 X11 | 词条缺失、粒度、物种路由、同义表 |
| L2 候选生成面 | 每簇候选排名（查询预算/槽位/别名） | stage_b_evidence + 生成器配置版本 | 查询预算、槽位竞争、族内去重 |
| L3 判读面 | 闭集判读/证据面/提示 | 判读算法版本 D + 判读合同 | 提示与决策顺序、闭集来源 |
| L4 计分/契约面 | 分母/映射/弃权计分 | 评测契约 E + 信息契约 I | 口径、crosswalk、未覆盖规则 |
| L5 门控面 | S0/体积门/守卫/逃生门 | 门控配置 + 逃生门开关 | 触发条件、短路盲区 |
| L6 交付面 | 镜像仓/评测集/文档 | 仓版本 + VERIFY_CONTRACT | 可运行性、对外措辞 |

件级登记与「谁能改、走什么门」见同目录 `PIPELINE_REGISTRY.tsv`（**97 件登记行**，快照时刻见 `REGISTRY_BUILD_REPORT.json.generated_at`：
L0 20 / L1 21 / L2 10 / L3 5 / L4 13 / L5 13 / L6 15；sha 逐件现取、禁凭记忆填；窗口内有写入的件标 LIVE）。

## 1. 首因层判定流程（改前必跑，四步 + 反例表）

### Step 0 — 现象陈述（必须先写读数与口径，禁写形容词）
```
现象：<一句话>
读数：<主读数 + 分母 + 口径>
来源：<盘上文件绝对路径 + 行号/列名>
禁项：不得用「看起来/普遍/大概率」作现象陈述；异常分先自验尸（公道律）。
```

### Step 1 — 逐层取证（每层至少一条**盘上实测**证据，取不到就标 UNVERIFIED）
| 层 | 本层取证问法 | 本层证据样例（今日在盘） |
|---|---|---|
| L0 | 卷构成/真值/泄漏是否合格？ | `gold/FREEZE_GOLD_X9A*.sha256`、`leak/LEAK_AUDIT_X9A.md` |
| L1 | 目标类的词条是否存在且被装载？物种路由是否正确？ | `kb/markers/*.json`、`mcp_server/eyekb_core.py` 的 `MARKER_LIBS` |
| L2 | 目标类是否进入候选面？查询预算/席位是否够？ | `C0_CANDIDATE_REACHABILITY.tsv`、`X10D/REACH_DIFF_X9A_X9B.tsv` |
| L3 | 提示/决策顺序是否使目标类不可达？ | `judge_x9a_arms.py`（闭集、brief_parts） |
| L4 | 分母/映射/弃权是否吞掉该现象？ | `M1_CONTRACT/*`、`score_engine.py` |
| L5 | 是否被某道门在判读前阻断？ | `C0_GATE_TRIGGERS.tsv`、`s0_check.py`、`volume_gate.py` |
| L6 | 是否只是交付/措辞/可运行性问题？ | `docs/VERIFY_CONTRACT.md`、`tests/verify_*.py` |

### Step 2 — 定层（首因层的定义要可判定）
**首因层 = 去掉该层成因后现象消失的、最上游的那一层。**
- 只「缓解」不消失 ⇒ 不是首因层（只是共因或下游放大）。
- 多层各自独立致因 ⇒ 分层登记，**改层清单须列全**（禁只修其一后声称解决）。

### Step 3 — 反例表（禁拍胸脯；逐层写"若首因在此层的预期读数"与实测对照）
| 层 | 首因若在此层，预期读数 | 盘上实测 | 判 |
|---|---|---|---|
| 例：L1 | 补词条后可达性显著上升 | 见教材案 1：补后 RGC top3 0.2339→0.3027，仍远低于同词表 top-30 的 0.8638 | ✗ 非首因 |
| 例：L2 | 放大查询预算后可达性显著上升 | 0.2339 → 0.8638（预算 10→30） | ✓ 首因 |

### Step 4 — 裁定落纸（写进任务书，缺一即不合格）
```
首因层 = L?
拟修层 = L?  （必须等于首因层；不等 ⇒ 不在该层修）
下游是否仍需补丁 = 是/否；若"是" ⇒ 补丁登记为过渡件 + 到期日 + 上游修复指向（+ 删除条件）
影响面清单 = <哪些臂/哪些读数会被动>
判据预注册 = <主读数/保护门/失败退出>
逃生门 = <开关名 + 回退后逐字节回旧行为的实证方式>
```

## 2. 今日四个教材案例（全部在盘、可复算）

### 教材案 1 — RGC 缺 76% 的首因在 L2 查询预算，不在 L1 词表
- **现象**：X9A 成人小鼠卷 RGC（47,261 细胞）在候选面上近乎不可达。
- **读数（盘上实测）**：
  - `C0_AUDIT/C0_CANDIDATE_REACHABILITY.tsv`：X9A/on/lineage/RGC → `reach_top1=0.2339 / top3=0.2339 / full=0.2339`；
  - `X10D/REACH_DIFF_X9A_X9B.tsv`：RGC 行第 17 列 `reach_top3_at_query30_diag=0.8638`（同一词表、仅查询预算 10→30）；
  - `X10D/WIRING_EVIDENCE.json` → `B_query_budget.X9A_on.all_top1_q30=0.8455`（全卷 top1，预算 30）。
- **反例表判读**：补词条（L1）后 RGC top3 仅 0.2339→0.3027（Δ0.0688、增益 3,249 细胞），而放大预算（L2）后同一批细胞到 **0.8638** ⇒ **首因在 L2**。
- **必答三问落位**：首因=L2；拟修层=L2（生成器查询预算配置版本化，见 DIRECTIVE §三①）；L1 补条仍可作为**并行**上游动作，但不得以「补了词表」宣称解决 RGC 缺口。
- **下游残留**：L3 提示词层无法补回（判读看不到未进候选的类）——L3 不是首因层。

### 教材案 2 — 补上游也要遵守上游自己的规则：3 席候选面的槽位竞争回退
- **现象**：向 L1 补小鼠细则词条后，一个**原本可达**的类掉出候选面。
- **读数（盘上实测）**：`X10D/REACH_DIFF_X9A_X9B.tsv` Astrocyte 行：`top3 0.8399 → 0.0`（Δ−0.8399、`loss_cells_top3=1652`）；
  `X10D/X10D_REPORT.md` §3.1 关键读法 2：机制=新条 `Muller_mouse_discrim`（GLUL+RLBP1）进入簇 13 的 top3 第 3 席，把原本第 3 的 `Astro` 挤出；
  同报告：strict 映射口径下增量**净 −0.0152**。
- **归因**：不是新条本身错误，而是 **L2 候选面容量/席位规则的缺失**（族内别名去重 + 保底席位属 L2 规范）⇒ 补上游的**动作**（L1 词表增量）必须在**上游自己的规则**（L2 席位规则）下执行。
- **落位**：L2 侧需出生成器候选面规则件（DIRECTIVE §三②）；当前实现只在**消费侧**守卫 `pipeline/kb9_slot_guard.py`，L2 侧**无权威件**（登记为缺口，见 `PIPELINE_REGISTRY.tsv` L2-06 / L5-03）。
- **纪律**：不单调性必须逐条登记（DIRECTIVE §二7：禁只报增益）。本表 `__ALL__` 行同时给出增益 3,249 与损失 1,652。

### 教材案 3 — 小鼠卷走人判断路径：L1/L5 治理缺陷，L3 提示词补不回来
- **现象**：小鼠卷（X9A）的候选排名按**人行符号库**产出，跨物种治理门未生效。
- **读数（盘上实测）**：
  - `X10D/WIRING_EVIDENCE.json` → `D_threshold_gate.kbgov_g1`：X9A_on / X9A_off / X9B_W / X9B_R **全部** `reported_input_species="human_assumed"`、`no_named_ranking_for_present=false`、`title_frac_max=0.0`；
  - `C_generator.X9A_on.libs` = `[retina, membrane, retina_interneuron, retina_v6, face_v6, k9_ocs]`（人行符号库全量装载）；
  - `X10D/X10D_REPORT.md`：`Pericyte` 键在 `membrane` 库存在，但**鼠卷查询命中 0**（符号体系不匹配的现场证据）。
- **首因层**：**L1 物种路由（符号大小写/物种判定优先级）+ L5 治理门短路**（DIRECTIVE §三③ 定层为 L1/L5）。
- **反例表判读**：若首因在 L3（提示词），应在**不动物种路由**的前提下经提示词改善 ⇒ 实测候选面根本没进（命中 0），提示词再怎么改也无对象可判 ⇒ **L3 不是首因层**，下游提示词补不回来。
- **落地要求**：L1 物种路由规范（符号大小写归一 + 物种判定优先级 + 小鼠卷必走鼠路径）+ L5 治理门短路消除，**含测试用例**（DIRECTIVE §三③）。

### 教材案 4 — 判读闭集从评估卷 gold 派生：L4 契约缺陷，下游提示词改不动
- **现象**：判读的可选标签集不是独立权威件，而是**从被评测的那一卷的真值文件现取**。
- **读数（盘上实测）**：`plans/x9_fresh_20261012/s1_adult/scripts/judge_x9a_arms.py`
  - 第 27 行：`LABELS = [r["truth"] for r in csv.DictReader(open(GOLD_FINE), delimiter="\t")]`
  - 紧接：`assert len(LABELS) == 26`；docstring 第 3 行自述「闭集=本卷 gold fine 类（26 类）+ unknown」。
- **归因**：命中的是 **DIRECTIVE §二8 真值红线**（任何层不得从评估卷 gold 派生口径/词表/映射）与 **L4 契约**（合法输出集应为其自身冻结件——本波已出 `M1_CONTRACT/legal_output_sets_X10C.tsv` 正是修复形态）。
- **反例表判读**：若首因在 L3（提示词写法），则把同一提示词喂给一份**独立闭集**应表现不变；而现实现下闭集与卷真值强绑定 ⇒ 跨卷不可比、且违反真值红线 ⇒ **首因在 L4**。
- **下游纪律**：L3 的提示词/决策顺序改动**不能**修复本缺陷；修复必须落在 L4 契约件（合法输出集独立冻结 + 新增弃权只改输出状态、不改分母）。
