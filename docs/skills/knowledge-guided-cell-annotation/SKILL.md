# 知识库引导的单细胞注释判读体系（EyeKB 模式）

## PI 教义（2026-09-23 原话拍板，任何注释任务动手前先读）

1. **注释有两个独立维度，缺一即废**：
   - ①**标注对**——动手前必须知道该物种该组织的细胞组成清单和大致比例（组成先验），注释结果必须能在先验里定位，定位不了→旗标 unexpected 报审，禁硬标
   - ②**分得开**——降维聚类必须真分开，判"分不开"的簇**不硬标**，旗标 split-or-report 交 PI；混着的簇注释毫无意义
2. **加进知识库的东西必须有理由有依据**：无出处（PMID/数据集+证据等级）条目禁入；文章按"放进去的原因"归类进 RAG（inclusion_reason）；最后用 wiki 建链接
3. **先验不是真理**（PI："我们 PDR 的那个注释也不一定准啊"）：先验与数据打架→旗标上报，禁改数据凑先验；真值在 PI 临床判读手里
4. **疾病上下文要进判断**（增殖期糖网→预期血管增殖/tip cell 态），但规则只当**先验和 QC 旗**（expected/unexpected/contamination-suspect），不当最终标签——防先验锚定偏见

## 知识判读层结构（三层，全部带证据溯源）

| 层 | 内容 | 条目结构 |
|---|---|---|
| 组成基线 | species×tissue → 细胞清单+比例**区间**（图谱数据驱动+文献锚，禁伪精度） | 逐细胞类型：预期比例区间+PMID+证据等级 |
| 疾病条目 | disease×tissue → 上下文/预期细胞矩阵/非预期旗/污染旗（血液/色素/裂解） | **细胞类型 × 状态** 两级（Macrophage: homeostatic MRC1+ / 泡沫样 GPNMB+ / 炎症 CCL3+） |
| 本地 marker 权威层 | cell type 面板 + 基因反查 | 逐 marker 带来源（canonical 或 PMID/数据驱动出处）+版本号 |

- **防库膨胀铁律**：疾病特征大多是"状态"不是"新细胞类型"，条目按类型×状态两级组织，否则重复条目失控
- **覆盖按样本入口疾病谱滚动**（PDR 膜→AMD/RPE-脉络膜→青光眼视神经→眼表），禁"所有疾病一次性搞完"大坑；新疾病数据进门时顺手建条目（每条 0.5-1 天边际成本）

## RAG 按入库原因归类（PI 硬要求）

- 论文级 additive 字段 `inclusion_reason`，枚举冻结：`composition_baseline` / `disease_cell_composition` / `state_signature` / `method_reference` / `disease_mechanism_background`
- additive 元数据，不动 chunks 文本与向量；存量半自动归类+抽样人工核验；缺口补集按原因检索补入（语料即"判读依据库"，不是无目录的文献堆）

## human-in-loop MCP 注释模式

```
聚类 marker 提取
  → agent 调 MCP：query_marker（本地优先纪律）→ search_literature（文献证据+PMID）
                  → get_disease_prior / get_tissue_composition（先验对照）
  → 草稿标签 + 置信 + 文献依据
  → PI 确认/改判 ← 人机交互核心，两层分歧本身是 QC 信号
  → 定稿写回 obs
```

- 草稿文件头必标：`【草稿待 PI 确认 — human-in-loop 模式, 非引擎自动注释】`
- 全程 MCP 调用 jsonl 留痕（可复现链）；每簇给 top markers + 本地 KB 命中 + 文献证据 + 置信 + 组成
- **服务层合格门**：三工具自测 + 黄金回归（同查询 MCP 调用 vs 直调返回**逐项一致**含 PMID 序与分数，41/41 实测标准）
- MCP 本地 stdio 不开网络端口；RAG/先验只作引用与对照，**禁入打分**（Claude5 冻结裁定跨项目继承）

## REVIEWER_LLM 方法论裁决（2026-09-23 送审回稿，协议 v2 修订依据——与上文冲突处以下为准）

总体判：方向对，但证明范围必须限定——工程回归（黄金集 10/10、MCP 41/41）只证工具层不失真，**不证疾病组织标签正确**；项目主线从"扩知识"转向"建可审计的正确性证据"。

- **两维度→两目标+三道门**：身份证据门 / 群体解析度门 / **技术可信度门**（双细胞/环境RNA/低质量/供者效应/整合引入结构变化）。双细胞率是技术指标非解析度指标，禁全局固定阈值（按 文库×细胞大类×标签层级 校准：开发集选→独立供者验证→冻结）；UMAP/silhouette/批次混合度不单独设通过门
- **"分得开"的正确姿势**：连续状态（单核→巨噬、激活、增殖）允许存在，强迫拆分=制造假亚型；split-or-report 扩为**三处置**——有证据才拆/保留更粗标签/报告连续未解析群体，拆分不是默认补救；分辨率稳定性评估"身份结论"是否保留，非簇编号稳定
- **组成基线锚分级**：主锚=同物种+**同取样材料**+同疾病阶段可比数据（PDR 膜主锚=纤维血管膜数据集，健康视网膜只作身份参考降级；玻璃体液将来单独基线）；条目必记：取样材料/疾病阶段/治疗背景/scRNA vs snRNA/富集步骤/供者数；比例=条件性参考分布非目标；按**供者级**分布统计（勿合并后把大供者当强证据）；文献只有定性描述就存定性禁补造区间；缺比例不阻断注释
- **防锚定四阶段**：①数据优先（隐疾病分组）完成 QC+候选身份+冻结 ②疾病对照（只出一致性/冲突旗标+引用）③改标必须给新数据证据（"更符合疾病预期"不构成改标理由）④PI 裁决保留改标前后标签。on/off 对照须独立判读组或顺序平衡（同一人先看 on 再"盲评"off 无效——PRIOR_DIFF 类设计要按此加固）
- **unexpected 四分类**：超出基线覆盖/与现有资料冲突/技术可疑/候选生物学现象——分队列处置勿混一锅
- **类型×状态实施**：分层身份+多个可并存状态轴；稳定概念ID↔规范名↔同义词映射防膨胀（名称相似不自动合并、名称不同不自动拆分）；证据记到图表定位+反例+适用条件；转录相似≠发育来源
- **RAG 三字段**：inclusion_reason（五类多选）+ claim_relation（支持/反驳/限定+具体论断定位）+ evidence_context（物种/材料/条件/图表锚点）；一篇论文不同段落可支持不同论断；50 篇随机抽检≠正式验收，D0 规则关键论断**逐条核验**+未核验条目标状态
- **T6 项目优先级**：①分层注释评估集+冻结评估协议（供者级开发/测试划分，报告错误率/覆盖率/弃权率）②独立 PDR 材料外部验证+关键争议正交验证 ③D0 判读闭环收益验证（指标=经独立复核确认纠错数/引入错误数/合理保留未定数/复核耗时，**非"改了多少标签"**）。暂缓：人鼠对齐、疾病层铺宽、v2_prod 切换（只限成人视网膜域独立评估）；M1 定位="有明确适用域的眼科注释基础设施"，知识库规模不是方法学贡献中心
- **T7 无 ground truth 的正确性标准**：逐簇证据卡（候选身份+替代候选/跨样本贡献/正反证/技术解释/整合前后稳健性/裁决接受到哪层级+未解决项）；独立性按供者算（同供者数千细胞≠数千次独立验证）；**域外使用审计是第一审计项**（引擎/marker 库适用域 vs 样本材料匹配性）
- **manifest 口径完备性**：species 分类计数加总必须=总行数（实测 other+unknown+method 13,514 差额被 REVIEWER_LLM 抓出质询），未标注类在过滤检索中的行为要写明防隐蔽漏检

## 注释评估集：真值只用现有已注释数据集（PI 2026-09-23 拍板）

- PI 原话"不用 pdr 了呗，就用现有的数据集就可以了？"——**评估集考卷全部来自作者/portal 已注释公开集，无真值的疾病数据不当考题**；PDR 等降为"疾病挑战层"（只评 A/B/C 证据分级与弃权行为，不计对错），其真实注释走 human-in-loop 模式
- 六层结构：E1 成人视网膜外部 5 集（跨平台主战场）/ E2 HRCA held-out donor（防自测作弊）/ E3 眼表 held-out+limbus / E4 鼠 held-out（只评判读层，人引擎对鼠是冻结 OOD）/ E5 OOD 严格层（胎儿+Astro/MG 混标集，评"该弃权时弃权"）/ E6 疾病挑战层（无真值）
- 纪律：考卷先冻结再开考（防挑数据）；首轮只出基线分布不设及格线；弃权=合法输出；供者级划分（REVIEWER_LLM T7）；副产品=G1 vs v2_prod 同卷对比（历史挂账拍板项的定量弹药）
- 设计考卷前先核 registry 的物种/发育标注正确性（实测 GSE137400 分档表物种标错，勘误流程触发——**考卷带毒比没考卷更糟**）

## 双盲判读评测运维（2026-09-24 KB2 首轮实证）

- **证据面组装脚本必须"空值即失败"**：digest 生成器对 40/45 簇静默产出空 top_genes（簇号 int/str 错配，`if c not in gm` 恒真不抛异常、日志全正常），缺陷件流入判读员才被阻断——组装判读证据卡的脚本必须带**逐行非空断言+行数断言**作为冻结前置验收；判读员对空证据"拒绝产出、发阻断报告"是正确行为范本
- **判读员与 debug 者必须分离**：为定位根因读 clustering TSV/取证材料即污染盲性（实测 AGENT_ROLE 自曝 2 个 barcode 真值暴露）→ 修复后该槽位必须**重开干净卡**，盲性红线写进任务书（禁 truth 列/引擎预测/另一判读员产物/errata 取证件/外部检索；undetermined 合法）
- **人类 PI 占判读槽位优于双 AI 互判**：同证据面下"临床专家 vs AI"一致率更贴 human-in-loop 定位。PI 走 MSG_PLATFORM 分批判读包（每批=一个成员 5 簇，大白话回身份+等级+依据，协调者忠实转录 JSONL）；槽位文件名保持评分脚本兼容，换人时 README/任务书声明实际判读员
- **缺陷件重建纪律（errata-source-fix）**：旧件 `_defective` 后缀保版本+sha 日志；最小补丁照阻断报告提案原样执行；重跑后**先验冻结选择不变**（rng 消耗序不变⇒同题，逐成员 str 化比对）再接受；协调者重跑前先按库版本枚举 env 并对每个数据源 test-read（anndata 0.11 读不了 0.13 写的 h5ad null 编码，实测 pipeline_env 死、scrnaseq 通）

## 评测运维·规模期（2026-09-24 RUN2/RUN3 实证，LLM 批量盲判阶段）

- **LLM 批量盲判 runner 配方**（≥100 簇时取代 worker 卡，worker 卡容量上限实测 ~45 簇/2h）：每批 5 簇（按成员分组防跨组织混淆）→ JSONL 逐行解析+缺失簇补判调用 → 断点文件（`.done.json` 每批落盘，崩溃/超时续跑不重做）→ 全量才写终件。温度 0.2；**混合推理模型必须显式关思考**（qwen3.8-max 带思维链时 5 簇批 >300s 读超时，`enable_thinking:false` 后 0.7s 级；dashscope 兼容模式支持，`thinking:{type:disabled}` 亦可）
- **模型选定前三件事**：①端点 /models 或 smoke 实测（配置引用过的名字不代表可用——Agents-A1 在 maas 端点 404；profile config 里 api_key 可能是脱敏存储"sk-xxx...yyy"不可用于脚本）②回空内容的模型不用（deepseek-v4-pro smoke 返回 content=''）③A/B 跨厂商独立性记进预注册（实测 qwen 系 vs glm 系真值命中差 10pp，模型选择本身就是实验变量）。**探针一律落成脚本文件执行**（读 config 提 key 的逻辑在脚本内自包含）——shell 内联 curl/python heredoc 携带 key 外发会触发安全审批墙（实测两次挂审批等超时被 BLOCKED），且审批超时后勿原样重试、改脚本路径执行
- **PI 判读的 LLM 评审环**（PI 说"你去找X评审吧"=工作流而非客套）：PI 提交判读表 → 强模型独立评审（喂同一证据面+规则，逐簇"同意/部分同意/异议+钉到基因"）→ 分歧点回呈 PI → PI 一字裁定（"降 C"）→ 转录件记 pre/post。评审员禁见另一判读员产物。本轮实证：qwen3.8-max 评审抓住 PI 的"可排除 B/浆细胞"过强表述（IGKC/MZB1 浆重叠+51 细胞小簇），PI 采纳降 C
- **证据面数据构建铁律（PI 原话"ENSG 后面可以直接加一列"）**：ID 转换/映射一律**原值保留+旁列存映射结果**（top_genes 原 ID + top_genes_sym 按位 1:1，映射不上留空、下游回退原 ID），禁止原地替换——可审计性优先于简洁性；此规则适用于一切判读面/交付表构建
- **规模偏差先声明后执行**： workload 超出原设计容量（如 B 侧 worker 卡装不下 290 簇）→ 在预注册件加 deviation 段（改法+独立性论证+判据不变）再动手，禁静默换架构
- **评分器跨轮复用**：输出路径带轮次前缀（run{N}_*），复制旧版改前缀，绝不覆盖历史轮产物；崩溃修复（如 pandas value_counts tuple 键进 json）也走版本化文件
- **锚卷机制**（跨面翻转测量）：上轮全部簇原样混入本轮新面，同判读员跨轮翻转率=证据面升级的净效应探针（RUN3 实测 8/40，其中指向已登记修复的 2 处翻转=修复生效的直接证据）

## Pitfalls（2026-09-23 GSE165784 PDR 膜 demo 实证）

- **本地 KB 盲区**：健康图谱 marker 库套疾病样本→血管/间质/免疫全 0 命中（PDR 膜髓系占 80%、健康视网膜库 10 类 0 覆盖）→ 库必须含疾病态/膜类/免疫面板
- **batch 混进簇边界**：某簇几乎全来自单一样本=样本效应信号；整合（harmony 等）+ 整合前后**双轨 marker 一致性核对**（防整合抹掉真信号）
- **n=1 对照**：组间只做描述性对比，禁统计断言
- **意外簇是机会不是错误**：unexpected 签名先疑 doublet/污染，但核实后可能是有价值的发现，保留旗标
- **diff 表纪律**：任何重聚类/优化必须产 v1→v2 diff 表（每簇去向+纯度+语义变没变+依据），旧版全产物保留
- **防疾病中心收窄（PI 纠正"为什么聚焦在 pdr 上，我们做的是眼科通用的啊"）**：判读层架构=组织锚通用层（组成基线锚 registry **已注释标准集** D001/D002，其余组织骨架等盘点回填不硬凑）+ 疾病薄层矩阵（疾病只是填格子，一个格子而已）；评估真值只用已注释数据集。新场景先问"通用层怎么覆盖"再问"疾病条目怎么填"，禁止把整个架构围绕单一疾病/样本设计
