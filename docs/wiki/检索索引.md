## 1. RAG 文献查询（最常用）

```bash
cd /mnt/D/OcularKB/ocularkb/rag
/home/ubuntu/.conda/envs/pipeline_env/bin/python scripts/stage3_retrieve.py \
  --cell-type "keratocyte" --species human --tissue cornea \
  --db-dir literature_db/v2.0_2026-09 --top-k 5
```

- 三维过滤：`--cell-type`（必）+ `--species`（human/mouse，含 both）+ `--tissue`（11 组织标签：retina/cornea/conjunctiva/sclera/trabecular_meshwork/iris/ciliary_body/lens/optic_nerve/RPE/choroid）
- `--db-dir` 不给 = 默认 v1.0（旧行为兼容）；**项目现役请显式给 v2.0**
- 返回：PMID + 期刊年份 + 物种 + 文献片段 + marker 基因 + 相关度
- 用途边界（2026-09-26 PI 拍板改写作"证据消费纪律 v2"，见 USER_DIRECTIVE_20260926_redline_rewrite.md）：**注释/判读侧消费 RAG/MCP 证据=合法且为核心设计；判分/裁定侧（真值匹配、命中率、共识裁定、任何自动打分/置信加权）禁食判读同源证据**（红线，防循环自证）
