## The project in one sentence

Automatic cell-type annotation for ophthalmic single-cell data: a literature evidence library (RAG) + an annotation engine (HRCA reference + LR model + marker reverse-exclusion) + a marker data-retrieval discipline skill. The benchmark is "the ophthalmology version of CellTypist" — the atlas is the textbook, the tool is the referee (the standard reporting line to the PI; do not pile up jargon).
