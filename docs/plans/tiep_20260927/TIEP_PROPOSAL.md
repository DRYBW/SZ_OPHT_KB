## 0. 一句话结论

现行三票多数制把"平局"错诊为问题——**全盘 90% 的 tie 其实是"单有效票"（tie@1，其余票被 grade-C/粗判弃规则弃掉）**。
三种候选破缺规则里：**C2（法定人数，两席同名即定名，grade 不弃）在 KB9 面零成本 +7 命中（22→29/33，过 ≥24 门）**；C3b（单票+S1 证据确认）与 C1（grade 加权）增益相近但各自引入"单席定罪"式新错名，且全部候选规则在 RUN5 旧票面会顶破 P2 污染门（≤1→2~4）。
建议档 = **C2b 主档，附 C2a 保守档**；C1 不推荐单独采用；任何采纳均需预注册 protocol v2 后自下一 run 生效，不回改历史冻结裁决。

## 2. 反事实重投票（任务 2）：规则 × 数字

规则操作化定义（全部机械，实现见 `scripts/t1_revote.py`）：
- **C4 基线**：定名票且 grade∈{A,B} 计票；≥2 同名定名；否则无名（tie/split3/abstain3）。
- **C1 grade 加权**：定名票任意 grade 按 w 加权求和取严格最大。默认档 (A,B,C)=(1.0,0.8,0.4)；网格 wB∈{0.6..0.9}×wC∈{0.1..0.6} 共 24 档。
- **C2a 法定人数**：定名票任意 grade 计数，≥2 席同名即定名。
- **C2b 法定人数+粗判入数**：同 C2a，另 coarse:X 计入标签 X 的法定人数（"第三席粗判不弃全"宽读法）。
- **C3a S1 具名破平**：仅对真并列（并列标签≥2）用 E2 去同源证据分 S1（n_shared_decon，经 e1_class_map 冻结映射，同候选取 max，AMBIG 不给分）取严格最大具名；S1 并列=不具名。
- **C3b = C3a + 单有效票具名**：tie@1 时若该标签 S1≥1 则具名确认。

**核心安全性质（硬校验，`out/flip_lists.tsv` 204 差集全量逐条含票面原文）：五规则 × 五面，无任何一例改动既有"已定名且正确"的结论（OVERTURN=0、was_published_hit 改动=0、改名/丢名=0）。所有改动只发生在 C4 判无名的簇上——"定名/不定名"二元，禁静默改判在结构上成立。**

## 4. 建议档与勾选位（任务 3；勾选归 PI）

**建议主档 = C2b（法定人数，含 coarse 入数）**：
- KB9 面 +7/0、P1 22→29、P2 零暴露、结构上不可能改判既有正确结论；RUN4-r/FACEV21 两门面无任何扰动（19/15 原样、保全条款原样）；
- 代价：coarse:X 语义跃迁（把判读者自报低分辨率票当定向票入数），KB9 面 7 例全对是小样本(n=3)实证，非保证。
**保守档 = C2a（coarse 不入数）**：+4/0、26/33，同样全部门面无扰动——若 PI 不接受 coarse 语义跃迁，C2a 是无脑安全的最小增益。
**C3b 不建议与 C2 叠加**：增益集在 KB9 面被 C2b 完全覆盖，且其单票确认机制在两门面引入 3 例新错名（S1≥1 门槛太松——1 个共享去污基因即放行）。
**C1 不推荐单独采用**：唯一同时改善 RUN4-r 双门（16/0）的规则，但"单席定罪"4 例错名+网格不敏感，历史 2 席面高净增（+32）不可外推到 3 席现行面。

无论选哪档，建议附三条执行条款：
1. 采纳 = 新预注册（protocol v2，票规则章节增补），**生效范围=下一 run 起**；五面历史裁决不回改（本模拟即改判依据时，RUN5/RUN4-r/FACEV21 的已发布件数字仍是历史冻结值）。
2. 若同时要求 P2 门不破：C2 档下新增定名簇自动进 P2 污染检查（KB9 面实测 0，无需改门）。
3. 词表漂移独立登记：票面出现盘外名（Keratocytes/Mac_DAM_LAM/coarse:Stromal 等，判读语义正确但字符串不等于真值词表）——此问题任何 tie 规则都不解决，建议 protocol v2 一并加"票面名过冻结 crosswalk 归一"条款。

## 5. 局限声明（判读纪律：任一规则若使既有 PASS 案翻错，直说）

1. **直说清单**：无既有 PASS 案被任何规则翻错（OVERTURN=0 硬校验，§2 表）；但 RUN5 旧票面下，任何"多定名"规则都使 P2 污染门破线（1→2~4）——若 PI 打算"用新规则回改 RUN5 结论"，那本身是门失败，不是翻案收益。
