**Q1：按所报口径，门③ FAIL；主因倾向上游清单与覆盖目标错配，但证据不足以认定执行完全无缺陷。**  
16 项漏配、6 项只配备选、1 项误引，指向上游问题；另 2 项属于必补论文可获取文本不足，“8 项仅备选覆盖”应据此细分。  
完整归因仍需冻结的“92 单元—候选 PMID—实际入库文本—消除结果”矩阵及获取、解析日志；“64 篇处理成功”不能证明内容完整。  
“文本提及∨链入库”须有事前规则支持；即使符合原规则，也只证明该代理指标改善，不能充分证明组织语境缺口消除。语境核验并不必须依赖 LLM。

**Q2：事后解释失败原因不构成移动球门；80% 阈值、92 单元分母及事前判据应保持不动。**  
将闭集执行完成改判为三门通过、删除未配文单元或事后放宽消除标准，才构成改变验收条件。  
通过至少需要 **74 单元，当前差 7 个**；“未配文”不等于闭集论文中不存在相关证据，16 项漏配本身也不能证明不可达。  
“闭集内无合法手段”尚未充分证明：须排除同一论文可获取全文未取得、解析遗漏及按既定规则漏检，并证明闭集最多只能消除 **73 单元**。

**Q3：推荐 B；追加获批前按 A 暂存 v2.4，整体验收保持 FAIL，无须仅因门③失败而全部回炉。**  
追加授权必须是核验题名—PMID对应关系及目标语境后形成的、逐篇去重的 PMID/DOI 白名单；“16 基因 top 候选”“约 20 篇”不能充当下载边界。  
同时锁定目标单元、允许获取形态、精确篇数及 ≤6MB 上限；替换论文、新增转引论文或超限均重新报批，104 篇备选也仅授权明确勾选项。  
v2.5 沿用原分母、阈值和事前判据，重跑三门，并核验已计入的 67 项证据有效性；追加审批不追认 v2.4 已通过。

**Q4：误引抽样不自动推翻门①②的回归 PASS，但限制其能够支持的正确性结论。**  
6/20 是抽中旧链的确诊比例；随机种子本身不能证明概率抽样，外推至总体 55 条须交代抽样设计与不确定性，不能直接套用于新增 64 篇。  
v2.4 全量继承，因此旧错链若仍被检索或展示，就继续影响版本质量；“新增论文不引用旧链”不能消除这种影响。  
须追踪确诊及存疑链是否参与黄金答案、retina gate 或 67 项消除；若参与，应校核受影响的正确性结论并重测，同时保留原始回归记录。

**Q5：门①按任务书“黄金41/41 off全等”判 PASS 成立；“契约过期且非本卡所致”只能条件成立。**  
应补充同环境下该契约在本卡变更前后均失败的结果，以及其他卡注册导致计数变化的可追溯差异；冻结面哈希一致提供支持，不能单独证明运行态归因。  
还须区分过期的绝对计数与仍应成立的“+10”行为关系；若后者失效，不能仅以快照过期免责。  
保留契约 8/9 的失败记录并另行修订；按题述九项未被纳入预注册门①，因此不自动否决其 PASS，但服务冻结面不变也不能证明 v2.4 接入后的表现。
