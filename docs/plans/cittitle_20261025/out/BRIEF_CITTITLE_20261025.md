# CITTITLE — 引用侧上游缺陷：884 条引用记录根本没有题名（缺陷修复）

## 事实（LINKKEY t_83c4324d 产物 + 协调者复算）
`kb/link_registry/LINK_REGISTRY_v1.jsonl` 的引用记录里：
- **884 条题名栏为空**（reason_code = TITLE_EMPTY_CITED）
- **116 条题名被硬截断到 120 字符**（TITLE_TRUNCATED_120）
- 2 条预印本 ID、1 条题名被改写
后果：任何按题名的核对/审计都只能对上约 30%，看起来像"两库对不上"，实为引用侧生成时没落题名（**不是语料侧的问题**：这 1,003 条全部 reachable_by_pmid=yes）。

## 交付
1. 在 `build_link_registry.py` 层面补出 `title / doi / pmcid` 三列（题名不截断，或截断但保留全长字段），从语料侧按 `paper_id == pmid` 回填。
2. 反事实证明：改后按题名的对上率（严格/前缀）必须显著提高，并给出改前/改后对照；未对上者逐条给原因。
3. 旧件并排保留 + 哈希留档；registry 行数与既有 165 行内容逐字节可核（除新增三列）。
