**Q2：修正。**  
Tier2 当前会把弱相关、全文索引位置不明的基因直接变成真值面板成员，且已实际污染 ACINAR、IMMUNE 等群；不能按当前规则进入 0.7 主门。具体方案：Tier1 基因进入主面板；Tier2 仅进入次级敏感性面板，不参与主面板 score、0.7 门或首二次比值，也不参与主参考群锚定。Tier2 可在附录中报告，并用于预注册的敏感性分析。若必须保留 Tier2 进入主门，则至少要求 abstract 可见、明确泪腺而非泪囊/疾病语境、且来自两个不同 PMID；当前干跑结果不足以支持其主门用途。

**Q3：否决当前实现，采纳替代方案。**  
“最高群检测分数率”不是纯度：它受群面板大小、基因表达可检测性和面板组成影响，不能解释为簇内细胞纯度；当前 ACINAR 约 15 基因而 MYOEPITH 约 5 基因，存在结构性偏差。具体改为：

- 主锚定分数使用每个基因在簇内细胞中的检测比例，先在群内汇总为每细胞检测率，再取群内基因检测率的中位数或预注册的截尾均值；
- 群间比较前，以独立的、等权的基因贡献计算群分数，避免面板大小直接决定得分；
- 0.7 解释为“群内标记检测率的聚合分数”，不得继续称为纯度；
- 另加簇内细胞级 top-group 一致率作为描述性指标，不能事后替代主门；
- 在冻结前固定缺失基因、低表达基因和 ambient 过滤顺序。

若受 RULING 的“纯度”字面约束，至少应将名称改为“检测一致性门”，并明确其不是生物学纯度。

**Q5：修正。**  
“地板+9pp”只是解释性披露，不足以防止分母构成导致的伪有效。若最大群接近 60%，P1=60% 几乎没有区分能力，尤其在小分母下，单个簇即可改变结论。建议增加考试有效性前置条件，但不改三门阈值：

- 不满足构成条件时，按 O3/不可判处理，不得发放 P1/P2 定量结论；

**Q6：采纳。**  
`coarse:X` 只有在 X 可通过 crosswalk 映射到唯一参考群时才有计票意义；词表外泛名如 `coarse:epithelium` 映射为 `no_counterpart`，按定向弃权处理是正确的。必须补三点：

- `coarse:X` 先做 crosswalk，再决定是否计入；
- 多义或泛谱系名称不得强行映射；
- 计票表中区分 `abstention_no_counterpart` 与普通缺票/undetermined，避免 P3 把解析失败错误归为模型或词条错误。

**Q7：修正。**  
在不触碰 RULING 的情况下，最合规的增量不是并入类器官，而是预注册、固定的多分辨率敏感性层。建议：

- 主分析固定 `resolution=1.0`，保持唯一正式题面；
- 预注册一个不看结果选择的 resolution 网格，例如 `{0.8, 1.0, 1.2}`，每档使用相同预注册参数和随机种子；

- 若多档均达到有效性前置条件，主结论仍只能来自 1.0，其他档作为稳定性分析；
- 若 1.0 不足 8 个锚定簇，不能用其他分辨率挽救本 run 的主考试，除非在冻结文件中明确把网格定义为并列主设计并预先规定合并规则。

但这只能评估稳定性，不能凭空制造独立样本。当前最重要的增量仍是修正外部面板，而非增加聚类档数。

**Q8：修正。**  
除上述问题外，还有以下实质缺陷：

1. **主门面板目前几乎不可用。**  
   DUCT 和 ENDO 的 available=0，说明并非数据没有该群，而是语境门把整个参考群排空。用空面板证明“不能锚定”会把检索失败误判为生物学阴性。

2. **Tier2 实际存在明确错误语境。**  
   `lacrimal sac` 是泪囊/引流结构，不等同于泪腺；疾病蛋白组也不能自动作为泪腺细胞类型 marker 证据。必须排除这些语境后重跑，不能把当前 T2 结果直接冻结。

3. **Tier1/Tier2 检索规则不对称且不可重复解释。**  
   Tier1要求 title+abstract 同时出现基因和语境；Tier2只要求 title 含语境且总 hitCount>=2，允许基因 token 仅出现在全文索引。这不是“较弱证据”，而是证据对象发生变化。Tier2 应降为附加证据层，不能与 Tier1 混入同一真值面板。

4. **“每群每基因挂 PMID”不能替代 marker 语义验证。**  
   一篇文献中出现某基因不等于该基因是该群 marker。终表至少应记录命中位置、语境类别和是否具有细胞类型/marker 语义；否则参考系会把疾病关联、分泌蛋白、组织存在性误当成细胞类型证据。

5. **面板群定义和候选矩阵不匹配。**  
   DUCT/ENDO 的 canonical marker 全部 FAIL，说明检索式对泛细胞类型 marker 有系统性不利，而不是随机缺失。不能在不修正检索式的情况下把结果称为“诚实阴性”。

6. **七群数量不等导致锚定门偏置。**  
   当前 score 是“达到 CPM 阈值的基因比例”，面板大小和 marker 可检测性共同影响分数。即使不改变 Q3 主方案，也应在冻结表中报告每群 available 数、有效 marker 数、各 marker 的检测率分布，并预先规定最低有效基因数；否则 1 个基因即可让小群获得 1.0 分。

7. **ambient 过滤规则可能产生群别不对称。**  
   `CV<=0.3 且 median CPM>=2000` 的过滤是在群得分前机械执行，但没有说明按所有簇计算还是仅按可用簇计算，也没有说明零值、单细胞计数和极小簇如何处理。应固定 CV 定义、零值处理、计算范围和过滤后的最小有效 marker 数。

8. **P2 的分母未明确。**  
   P2 写的是“锚定簇中……簇数 <=1”，但没有明确是所有锚定簇、还是去除泄漏旗后的合格锚定簇。必须与 P1 使用同一明确的分析集，或明文规定 P2 的分析集；否则同一 run 可产生不同结论。

9. **P1 小分母没有不确定性保护。**  
   即便满足 8 个簇，60% 也可能对应 5/8 或 6/10，结论离散且不稳定。不能改门槛，但必须报告原始分子/分母、精确区间和逐簇结果，禁止只报告百分比。

10. **组织池的 donor/sort 构成可能使簇不独立。**  
    以簇作为 P1 分母会把同一 donor 或同一 sort 池贡献的多个簇当作独立单位。至少应报告每个锚定簇的 donor 和 sort 构成，并增加 donor/sort 集中度警示；若某一 donor 独占多个分母簇，应在结论中标注外推限制。

11. **类器官“体内语义硬套”不应只作为限制句。**  
    只要类器官进入全题面投票，就已经把硬套语义转化成定量结果。应从正式疗效分母和 P2 中完全隔离，而不是仅在 §10 说明。

12. **检索排除规则尚未完全冻结。**  
    `lacrim|tear|exocrine|gland` 过宽，`gland` 可命中唾液腺、甲状腺等；必须将组织语境、物种、细胞类型语义和排除词写入逐字规则，并保存原始返回及筛选理由。

13. **“不读取 KB8 面板”与显式排除 LYZ/LTF 存在审计风险。**  
    既然排除依据来自 KB8 完成报告，这不是完全独立于 KB8 的候选处理。应把 LYZ/LTF 排除标为预先登记的平台污染排除规则，并证明该规则不依赖本 run 聚类或最终结果；否则将其作为独立性限制披露。

**可粘贴的面板语境门最终文本**

> **§1.2 外部文献面板语境门。**  
> 每个候选基因仅可依据独立于 KB、KB8 面板和本 run 聚类结果的外部文献建立参考证据。Europe PMC 查询、返回内容、命中位置和筛选理由逐基因原样保存；同一 PMID 仅计一次。主证据必须同时满足：物种为人；组织语境明确指向 `lacrimal gland` 或同义的泪腺语境；基因 token 位于题名或摘要；文献语义指向细胞类型、marker、单细胞/转录组定位或组织细胞表达，而非仅疾病关联、体液蛋白存在性或一般组织检测。  
>

>
> **Tier1（主证据）**：至少一条记录同时满足：基因精确 token 出现在题名或摘要；泪腺语境出现在题名或摘要；并且题名/摘要具有细胞类型、marker、单细胞、转录组定位或等价的细胞表达语义。Tier1 基因可进入该群主面板。  
>
> **Tier2（降级证据）**：仅在没有 Tier1 时考虑。必须同时满足：至少两个不同 PMID；每个 PMID 的题名明确含泪腺语境；基因 token 在题名或摘要可见；至少一条记录具有上述细胞类型/marker/定位语义；且无泪囊、泪道或纯疾病/体液蛋白组语境。Tier2 基因必须标记为 `tier2`，不得与 Tier1 混写。Tier2 不得单独形成主锚定证据；若进入预先登记的敏感性面板，必须单独报告，不得用于替换主分析。  
>
> 只有通过主证据门的基因进入主面板分母。每个参考群须预先登记最低有效 marker 数；低于该数量的群标记为 `panel_unavailable`，不得以少数基因构成 0.7 锚定。所有群使用完全相同的检索、排除和证据分级规则，不得因预期结果调整规则。最终面板在判据件冻结后不得增删；最终面板不足以形成合格锚定簇时，依照 §8 的 `<8` 降档条款处理。
