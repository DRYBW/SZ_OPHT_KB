## 0. 一句话结论

同一个底模、同一个 checkpoint、同一套基因词表、同一条打分链，**只把 A1b 的参考索引的标签空间换成"含 X4A 金面自身那 16 类"**：

| | A1b × X4A lineage macro-F1 |
|---|---|
| 官方（我们的视网膜 189k 参考索引） | **0.3248** |
| 官方读数复算（run1 / run2） | 0.3242 / 0.3243 |
| 参考索引替换（run1 / run2） | **0.9893 / 0.9893** |
| + Müller 敏感臂（S2） | 0.9892 |

而 X2 式的**宽容别名层在 X4A 上一步都搬不动**：六臂 Δ lineage macro-F1 全部 = **0.0000**，
因为 X4A 上所有"落不进金面五档"的标签**全是视网膜神经元**（R4 红线禁止神经元→五档），
别名映射的是**标签**而不是**细胞**，神经元标签在金面五档里没有任何落点。

⇒ 两个原因**不同、且都已量化**：
- **A1a（eye-scGPT）的低读数是它自己的边界**：它 139,978 个细胞的输出词表里**没有**血管/基质类
  （Astrocyte 68,007 / Microglia 43,490 / BB 12,817 / GB 4,503 / HRGC9 1,931 / RB 1,801 / DB5 1,731 /
  HAC54 1,130 / RPE 992 …，零 vascular / 零 stromal）。
- **A1b（scGPT-base）的低读数主要在我们的参考索引**：它的答案空间是**我们**建的 189,049 细胞 / 31 类
  纯视网膜索引，kNN 不可能吐出参考里不存在的类。

**但这句话有边界，必须一起读（§3.6）**：参考与考卷同属一个 CELLxGENE collection（HRA006282），
参考=其 `source=Chen` 组分（813,508 核 / 58 供者），考卷=其 `source=Sanes` 组分，
两者**不同贡献研究、供者零重叠、细胞 id 交集 0**，但标注出自同一篇论文/同一套 pipeline。
因此本诊断**不能**把"答案空间边界"与"标注同源优势"完全分开。本卡按预注册要求：
**不更新主排名表、不更新 F_X4_RANKING.md**，此读数是**匹配参考诊断**，不是零样本读数。

|---|---|

### 3.4 参考索引怎么建的（含泄漏控制实核）

采用**优先级 1：study-disjoint 且盘上已有、零下载**（`work/ref_build_ledger.json`）：

- 来源 `/mnt/D/OcularKB/data/HRA006282_optic_nerve/HRA006282_optic_nerve.h5ad`（盘上原有）。

  **不取 `X`**——该文件的 `X` 是 log1p 归一值（每细胞 `expm1` 行和 ≈10,000，实测），
  用它会破坏"同一条链"的单变量要求（登记于 §5 D5）。
- 供者级隔离：排除 X4A 全部 19 供者 → 剩 813,508 核 / source=`Chen`；
  叠加成人闸（`donor_age ≥ 18`）→ **候选 713,438 核 / 58 供者**；
  HRA 上 X4A 供者的 146,121 核 source=`Sanes`（不同贡献研究）。
- **细胞 id 交集 = 0**（实测，ledger 字段 `cell_id_intersection_with_x4a`）。
- 标签空间 = **金面自己的 16 类**（identity 映射，逐字用 `engine_gold_x4a.tsv` 的 truth_celltype；
  5 档 lineage 由 `MAP_X4A_fine2super_v1.tsv` 派生）。
  `map` 21 个参考标签 → 金面 16 类（含 `blood vessel/capillary/venule/fenestrated endothelial` → endothelial cell、
  `retinal astrocyte`→astrocyte、`retinal pigment epithelial`→pigmented epithelial cell、`non-myelinating Schwann`→Schwann cell）；
  `drop` 31 个标签 / 71,681 细胞（全部视网膜神经元/光感受器/双极/无长突/水平/RGC/RPC + adipocyte/mast/dendritic +
  主臂的 Mueller cell）。**`drop` 就是"答案空间=金面本体"的实现。**
- 平衡抽样：每类上限 12,500、seed=20261024、稀有类全取 → **146,568 细胞 × 5,000 基因**
  （每细胞非零中位数 347；16 类**全部在场**，最小类 natural killer cell 310 细胞）。

  使 collator 看到的 `gene_ids` 数组与查询逐位相同。
- S2 敏感臂：把 Müller 一并纳入（`Mueller cell`→`(glia, astrocyte)`）→ 156,529 细胞。

### 3.6 这个读数能说什么、不能说什么（先于引用写清）

**能说**：A1b 的 X4A 低读数**主要**来自答案空间里缺了金面那几类；类补上以后，五档里的
stromal / vascular 从**结构性 0.0000** 变成 0.9818 / 0.9862，`n_invalid_projection` 从 53,621 掉到 **0**。

**不能说 / 必须一起披露**：
1. **参考与考卷同属一个 CELLxGENE collection（HRA006282）**：参考=source `Chen` 组分，
   考卷=source `Sanes` 组分——不同贡献研究、供者零重叠、细胞 id 交集 0，
   **但标注出自同一篇论文/同一套 pipeline**。`out/REFERENCE_LABEL_HOMOLOGY.json` 实测：
   **77,522 / 139,978（55.38%）的 X4A 细胞**能在参考文件里按"同供者+同条形码"找到同一颗细胞
   （这些供者已被排除出参考索引，**没有任何考卷细胞进索引**），
   这些同细胞在两份文件里的 `cell_type` 一致度 **93.45%**（16 类层）。
   ⇒ 本诊断是**匹配参考诊断，不是零样本读数**，它把"答案空间边界"与"标注同源优势"
   **同时**装进去了，本卡无法把两者完全分开。
2. **本卡不据此更新主排名表、不更新 `F_X4_RANKING.md`**（预注册明文要求，已执行）。
3. **不做 accuracy 宣称**：所有数字都是**命名一致度**（against 作者标签、in-sample 公开卷）。

## 4. 两类边界：分开陈述（本卡的存在理由）
